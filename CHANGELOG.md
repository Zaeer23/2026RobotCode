# Changelog

## 2026-10-24

- CyberPsycho mode: UP UP DOWN DOWN LEFT RIGHT LEFT RIGHT on either D-pad. Locks out every
  mechanism, raises the drive to the motors' free speed with a 60 A current limit, turns the
  Limelight into a plain camera, and sends the dashboard haywire. One way: only restarting the
  robot program ends it. See docs/robot-tuning.md
- Tests run one JVM per test class, so a test that boots the whole robot cannot break the next one

## 2026-10-20

- fixed the hi
- Dashboard redesign: dark FlatLaf theme, a status header on every tab (connection, mode,
  alliance, FMS, selected auto, match clock, battery), and a reworked Match tab
- New Autonomous tab: pick the routine with an animated field preview of the path, shots and
  timing, mirrored for the robot's alliance; the robot confirms the choice back
- Robot publishes the auto previews from the deployed PathPlanner files (`AutoCatalog`)
- Music tab: song search, saved playlists (create, rename, delete, add/remove songs), add files
  or whole folders; a broken MP3 no longer makes the player spin forever
- Dashboard.bat finds any installed Java 17+, not just the WPILib one
- Music: previous button, Space and arrow-key controls, drag and drop MP3s or folders
- 20 new 20-second autos ("R26 01".."R26 20"), four from each legal start spot, generated by
  `tools/generate_rebuilt_autos.py`; new `FeedCorral` named command feeds the human player
- Removed the five old autos: they started behind the ROBOT STARTING LINE (G303) and shot from the
  neutral zone (G407, MAJOR FOUL)
- AutoPathsTest now checks every auto against the 2026 manual (legal starts, shots only from the
  ALLIANCE ZONE, CENTER LINE, trench-only crossings, HUB and TOWER keep-outs); AutoCatalogTest
  checks each one fills AUTO without starving its last shot
- Dashboard field redrawn to the manual: starting lines, DEPOTS, OUTPOSTS/CORRAL, TOWERS, BUMPS,
  TRENCHES, hexagonal HUB openings and the neutral-zone FUEL
- Autonomous tab works with no robot: it previews the routines in this project's own files (marked
  "from laptop"), built by the same `AutoPreviewBuilder` the robot uses; the robot's catalog takes
  over when it connects
